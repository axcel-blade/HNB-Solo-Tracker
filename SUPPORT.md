# Support

## Need help?

1. Read the [User Guide](docs/USER_GUIDE.md).
2. Search [existing issues](https://github.com/axcel-blade/HNB-Solo-Tracker/issues).
3. Ask in [Discussions](https://github.com/axcel-blade/HNB-Solo-Tracker/discussions) (Q&A category).
4. Found a bug? Open a [bug report](https://github.com/axcel-blade/HNB-Solo-Tracker/issues/new?template=BUG_REPORT.md).

## When asking for help, include

- App version (bottom bar of the app)
- Windows version
- What you did, what you expected, and what happened
- A screenshot if possible

**Never post real customer phone numbers.** Replace them with dummy values such as `0770000000`.
