# User Guide

## Adding a customer

1. Click the **Phone number** box. It is selected automatically when the app opens.
2. Type the number, for example `0771234567`, and press **Enter**.
3. **Which bank?** Press `1` for **HNB** or `2` for **Other Bank**.
4. **Which product?** Press `1` for **Solo Max**, `2` for **Solo Credit/Debit Card** or `3` for **Solo Bank Acc**.

The number appears in its column and the counts at the top go up. The box is ready for the next number.

| Key | Action |
|---|---|
| `Enter` | Continue after typing a number |
| `1` `2` `3` | Choose an option in a pop-up |
| `Backspace` | Go back from product to bank |
| `Esc` | Cancel the pop-up |

## Reading the counts

- Each product card shows its total and the **HNB / Other** split.
- **Total collected** counts every entry across all products.

## Fixing mistakes

Open the **Transactions** tab, find the entry (use **Search**), and click **Delete**. Then add it again correctly.

## Exporting

Click **Export CSV** and choose where to save. The file opens in Excel with:
- one row per transaction (number, date/time, phone, bank, product)
- a summary table of counts at the bottom

## Starting fresh

**Clear all** deletes every entry after you confirm. Export first if you need a record.

## Settings

Click **Settings** (next to **Export CSV** at the top right). Click it again to go back. Changes are saved straight away.

| Section | What you can change |
|---|---|
| Profile | Staff name and branch, printed at the bottom of CSV exports |
| Data entry | Allowed phone number length; what happens with duplicate numbers (Allow, Warn or Block) |
| Appearance | Interface size (90% to 130%) |
| Export | The folder the save dialogs open in |
| Updates | Turn the start-up update check on or off, or check now |
| Data | Back up the database, open the data folder, reset settings |

## Updates

When a new version is available, a bar appears at the top. Click **Install update**, wait for the download, then click **Restart now**. Your data is kept.
